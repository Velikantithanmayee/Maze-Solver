# Maze Solver

An interactive web-based maze application built using Python, HTML, CSS, and JavaScript. The application provides a visual interface for working with a maze and exploring maze-solving functionality.

## Features

- Interactive maze visualization
- Web-based user interface
- Maze generation and initialization
- Visual representation of maze walls and paths

## Technologies Used

- **Python** — Backend logic using Flask (if configured in `app.py`)
- **HTML** — Webpage structure
- **CSS** — Styling and layout
- **JavaScript** — Interactive maze functionality

## Getting Started

### Prerequisites

- Python 3 installed
- Visual Studio Code or another code editor
- Flask, if required by the application

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/Maze-Solver.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Maze-Solver
   ```

3. Install Flask if the application uses it:

   ```bash
   pip install flask
   ```

4. Run the application:

   ```bash
   python app.py
   ```

5. Open the local URL displayed in the terminal in your browser.
